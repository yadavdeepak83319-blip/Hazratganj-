# Hazratgunj Restaurant & Banquet Hall

This ZIP contains the current Site package:

- `production/index.html` — the published website file, ready to upload to a static web host as `index.html`.
- `source/index.html` — the editable HTML source.
- `source/opengeni-source-bundle.json` — the original retained OpenGeni source bundle.

The page is static. WhatsApp links can be used for enquiries, but no persistent CMS, payment processing, or order/reservation backend is connected. The menu and photography are illustrative samples as identified on the Site; replace or confirm them and the business details before treating the page as a live restaurant website.
